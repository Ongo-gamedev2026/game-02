## 5️⃣ 스테이지 1 만들어 보기

> 📌 게임 전체가 아니라 **첫 번째 스테이지 하나만** 생각합니다. 스테이지 1을 만들려면 무엇이 필요한지 적어 봅니다.

### 5-1. 스테이지 1에서 일어나는 일

| 구분 | 내 게임에서는 | 예시 |
|---|---|---|
| ▶️ **시작할 때** | 키 설명하는 투툐리얼 UI | 플레이어가 화면 아래에 서 있다 |
| 🔄 **플레이 중** | 강력한 소가 나온다. | 위에서 생선과 폭탄이 떨어진다 |
| 🏆 **클리어 조건** | 목표 아이템을 얻을시 | 생선 10개를 받으면 성공 |
| 💥 **실패 조건** | 플레이어 무력화 | 폭탄에 3번 맞으면 실패 |

### 5-2. 스테이지 1에 등장하는 것들

게임 프로그램은 등장하는 것마다 **갖고 있는 정보**와 **하는 행동**으로 이루어집니다. 아래 표가 나중에 내 프로그램의 구조가 됩니다.

| 이름 | 갖고 있는 정보<br>(예: 위치, 목숨) | 하는 행동 또는 규칙<br>(예: 이동, 점프) |
|---|---|---|
| 🧍 **플레이어** | 오리는 한방에 골로 가는 허약체 입니다. 가까이 있는 아이템을 부리로 잡을수 있습니다. | 플레이어는 WASD로 움직일수 있고 QERF로 무장을 선택할수 있으며 마우스로 조준과 클릭시 발사까지 할수 있습니다. |
| 강력한 소 | 소는 둔함니다. 소가 머리를 돌리는 속도이며 이동속도 까지 전부 말이죠 하지만 체력이 높고 공격이 아야 할정도 | 일반 이동방식을 쓰며 가끔 돌격을 합니다. |
| 돌 | 오리가 잡을수 있는 아이템 맞으면 아야야 할정도 | 오리가 부리를 잡고 던질수 있음 |
|  |  |  |

> 플레이어 외에 몬스터, 퍼즐, 아이템, 장애물 등 스테이지 1에 꼭 필요한 것만 적습니다. 부족하면 같은 모양으로 줄을 더 추가해도 돼요.

### 5-3. 입력 방식

> 사용할 입력 방식의 `[ ]`를 `[x]`로 바꾸고, 어떤 입력이 어떤 동작이 되는지 적습니다.

- [x] ⌨️ 키보드
- [x] 🖱️ 마우스

| 입력 | 게임 속 동작 |
|---|---|
| 예: 스페이스 키 | 점프 |
| WASD | 전진,좌,후진,우 |
| QERF | 아이템 1, 2, 3, 4칸 선택 |
| MouseLeftClick | 뗴치(아이템 사용) |
